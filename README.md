# NBA Player Performance Analysis

## Project Overview
This project analyzes NBA player performance using the 2024–2025 season dataset. It uses Python and data analysis techniques to explore player statistics and identify performance patterns.

## Dataset
The project uses the [NBA Player Stats Season 2024–25 dataset on Kaggle](https://www.kaggle.com/datasets/eduardopalmieri/nba-player-stats-season-2425).

The dataset is downloaded automatically when the notebook runs, so the CSV file does not need to be uploaded to this repository.

## Requirements
- Python
- Jupyter Notebook
- pandas
- kagglehub

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   ```bash
   pip install pandas kagglehub jupyter
   ```
3. Open `NBA Player Performance Analysis.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.
5. Ensure you have an internet connection so the dataset can be downloaded.

## Project Files
- `NBA Player Performance Analysis.ipynb` — the notebook containing the analysis.

## Data Source
Dataset provided by Eduardopalmieri on Kaggle.
